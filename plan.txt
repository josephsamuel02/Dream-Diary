🔹 Syncing Flow (Common Approach)

Write to SQLite first (offline).

When internet is available:

Push new/updated entries from SQLite → supabase.

Pull new/updated entries from supabase → SQLite.

Use timestamps or updatedAt fields to resolve conflicts.

🔹 Tools / Patterns You Can Use

Custom Sync Logic:

Keep a column like lastSyncedAt in SQLite.

On sync, compare updatedAt in supabase vs SQLite and update whichever is older.

Background Sync:

Use expo-task-manager or an app focus listener to run sync in the background.

supabase Offline Mode (alternative):

supabase Firestore already supports offline caching.

This means you might not need SQLite at all — Firestore itself can act as local + cloud storage.
